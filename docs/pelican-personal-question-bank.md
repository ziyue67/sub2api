# 个人随机 SVG 题库

## 题库入口

管理员登录后，可以从以下位置维护同一份服务端题库：

- 账号管理 → 手动 SVG 测试 →「我的题库（随机）」→「管理题库」。
- SVG 分组测试 → 新建或编辑分组测试 →「我的题库（随机）」→「管理题库」。

每位管理员有独立的题库。每道题填写标题与题面，勾选是否启用，然后点击题库内的保存。题库最多 50 道题，标题最多 80 字符，题面最多 4000 字符。原有内置随机题库与固定自定义题面继续可用。

## 分组定时测试

选择「我的题库（随机）」后，先通过「管理题库」保存至少一道启用的题目，再保存分组测试规则。规则继续使用原有模型、频率、思考强度和并行份数设置。

规则保存时绑定当前登录管理员的题库，题库归属由服务器会话确定，请求不能指定其他管理员。另一个管理员打开规则编辑表单并保存个人题库模式时，会改为绑定该管理员自己的题库；页面会说明此行为。列表上的快捷暂停或启用会保留规则原来的题库归属。

定时运行和「立即运行」都在发送模型请求前抽取一道启用的题目，并冻结本轮题面。同轮的所有并行份数和账号故障切换共用这份快照；结果保存题目标题、题面与轮次。修改或停用题库中的题目不会改写历史结果，也不会改变已经抽好题的在途请求。

至少两道题启用时，避免重复上一份保留历史中同题库的题面；中间没有题面的准备失败记录不会重置这个判断。仅一道题启用时重复使用该题。历史沿用现有保留策略，历史被清理后下一轮不再有上一题可供排除。

没有启用题目时，启用状态下保存规则会被拒绝；运行前题目被全部停用时，不发送模型请求、不回退到内置题库。手动立即运行返回错误；定时运行保存一条零调用、零费用的准备失败记录，并释放运行锁，后续仍按既有频率检查。可保持规则暂停状态后补充题目，再重新启用。

## 兼容性

规则的题库归属沿用现有配置 JSON 保存，无新增数据库迁移。题库与快照只用于 SVG 题面准备，不修改模型定价、请求计费或原有分组路由算法。模型已经接受请求后，其费用仍按现有流程记录，不能把模型失败等同于免费。

本次只扩展分组定时测试；账号的其他定时测试、自动质量评分与既有任务类型保持原来的题面模式。降级到不支持个人题库分组规则的旧版本前，应先暂停这些规则，或将其改为固定自定义题面／内置随机模式。
