# BPS 工具目录提示词减重

普通 JSON Schema 在文本工具目录中使用紧凑表示，目录前提供一次语法说明。`"key":type` 表示必填，`"key"?:type` 表示可选，`[schema]` 表示数组，`...` / `...:schema` 表示额外字段策略。描述、enum、pattern、数值/数量约束保留为 JSON 注释；refs、union、条件结构、特殊数组与无法无损表示的形态保留完整 JSON。

改动仅影响提示词展示，原始 schema 仍用于参数验证，调用身份、工具 transport、排序和缓存作用域保留。没有增加原生 tool search，也没有移除上游 Excel 自带上下文。提示词布局变化可能使已有会话首轮缓存前缀失配。

## 本地测量

固定基线 `520c6de560fd07411346a652d47e97ea5979d693`，30 个唯一名称的合成文件工具，每个含 path/limit 字段、必填、描述与范围约束。只比较目录段，新版本包含一次 notation：旧版 12,058 字节 / 2,789 token，新版 7,378 字节 / 1,725 token；`tiktoken 0.14.0`、`o200k_base` 估算减少 1,064 token（38.15%）。这不是完整请求或线上计费节省比例。

验证：复杂约束/回退、确定性、原参数校验和现有工具回放/流式测试。未以真实模型验证提示词变化后的工具选择质量；真实客户端验收仍待部署者执行。
