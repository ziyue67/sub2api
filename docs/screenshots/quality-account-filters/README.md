# 检测账户筛选截图

Chrome 本地预览使用虚构账户、分组与 mock API，不连接生产服务。截图使用实际 `AccountQualityView`、`BaseDialog` 和页面样式，外层应用布局在预览中替换为空容器。

- `before.png`：`f80611d6c` 基线的新建检测规则抽屉。
- `after-desktop.png`：1280 × 900 视口，选择「主力分组」后全选当前筛选结果。55 个匹配账户分两页，跳过 1 个已有规则的账户，共选中 54 个。
- `after-mobile.png`：390 × 844 视口，保留相同筛选与选择。
- `after-english.png`：390 × 844 视口，英文界面。

图片裁剪到抽屉边界。筛选通过「账户分组」「账户类型」组合，搜索词输入后点击搜索或回车；「全选本页」只添加当前页可选账户，「全选当前筛选结果」包含所有匹配页。切换筛选保留已选账户；「清空已选」清除全部选择。
