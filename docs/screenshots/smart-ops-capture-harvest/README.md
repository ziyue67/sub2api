## 验收

- 修改前，请求采集是侧栏顶层第 2 项，打票流程是排在「智能运维」分组之后的顶层项，两个页面都没有智能运维的顶部标签。
- 修改后，两项位于「智能运维」子菜单末尾：自动配置 → 优先调度 → 质量运维 → 账号运维 → 凭证守护 → 凭证运营 → 鹈鹕测智 → 请求采集 → 打票流程。打开其中任一页面时，分组自动展开并高亮当前项；顶部标签与侧栏同序，两项的图标与其他子项同为小号。
- 关闭请求采集后（mock 返回 `request_capture_enabled: false`），侧栏与顶部标签都只剩 8 项；直接访问 `/admin/request-captures` 仍按原规则跳转到系统设置。
- 三张修改后截图对应页面的 `document.documentElement.scrollWidth` 都等于视口宽度（1440 / 390），没有横向溢出。手机端截图只展示首屏。
