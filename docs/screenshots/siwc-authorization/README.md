## 已确认的问题

旧组件把 “Continue with ChatGPT” 放在没有组件内或全局定义的 `link-btn` 样式上，没有显示完整授权 URL，也没有复制入口。原组件测试 mock 掉整个 SIWC API 模块，只检查授权表单展开和关闭清理，没有断言链接、提交回调或处理真实 Axios 归一化错误。

固定 Worker 依赖的原适配器测试只检查变换后的源码片段；密码/TOTP 测试则替换了所有登录 helper。这些测试通过不代表真实授权流程或可点击的页面已验收。

- 旧组件：复现只有文字链接、没有完整 URL 的状态。
- 新组件：确认打开入口的渐变按钮样式、可见完整 URL 与 `href` 相同、点击后新标签页打开该 URL。
- 回调：输入完整回调、提交、刷新为已绑定；账号协议仍为 Codex，需显式选择并保存。
