# 自动配置页面验证

使用构建后的前端、仅监听本机的 mock API 和 Chrome CDP 渲染。账号和分组均为虚构数据，保存只修改 mock 内存。

- desktop-zh.png：1440 × 1000，两个功能卡片并列。
- mobile-zh.png：390 像素宽，卡片纵向排列，检查页面无横向溢出。

本次是新增页面，没有同路由的旧版页面。实际新账号入库与并发升档由后端单元、竞争检测及 PostgreSQL 集成测试分别验证。
