# New API 上游钱包与分组查询

管理员可在账号列表的「上游渠道声明」列点击「不支持」，为 API Key 账号配置 New API 查询。配置后的倍率和余额使用其他账号的同一显示格式；点击倍率或状态文字可编辑配置，分组倍率的口径说明位于悬浮提示中。已有 Sub2API 声明查询继续使用原接口；未配置 New API 授权的账号也继续使用原探测逻辑。

## 配置与使用

1. 在上游 New API 的个人设置中生成**系统访问令牌**，并确认该用户的 ID。这里需要用户管理接口的授权，调用模型的 API Key 不能代替它。
2. 在配置弹窗填写上游用户 ID 和系统访问令牌，勾选需要同时配置的同站点账号，点击「预览」。不需要手动填写分组名称：服务会匹配每个账号已有的 API Key，读取其令牌分组。
3. 确认钱包余额、Key 匹配及分组结果，点击「验证并保存」。保存会重新验证所有所选账号；任何一个不匹配时，都不会部分保存。脱敏 Key 存在歧义时，选择对应令牌，再通过上游密钥接口核实。
4. 配置后可点击刷新查询，或使用现有自动探测设置。保存会打开账号级自动探测；后台定时刷新还受全局探测开关与间隔控制。

同站点、同上游用户的授权只加密保存一份。新填入的系统访问令牌会更新这份共享授权。已有授权时可留空复用；勾选的账号可以属于不同分组，但必须由该上游用户拥有。清除当前账号配置不会清除其他账号的绑定。

站点按协议、主机、有效端口与路径区分，忽略默认端口、末尾斜杠和末尾 `/v1`。例如 `https://example.com/tenant/v1` 与 `https://example.com/tenant/` 属于同站点；`/other/v1`、HTTP 地址或其他端口属于另一站点。同域名的不同用户不会自动共用钱包。

## 金额与倍率口径

钱包取自 `/api/user/self` 的 `quota`，除以 `/api/status` 公布的正数 `quota_per_unit`，显示为**标准化 USD**。这是用户钱包余额，不能由 Key 剩余额度或无限 Key 的仪表盘额度代替。上游以人民币或自定义单位展示时，页面显示值可能与上游钱包页面不同；本功能没有执行汇率换算。

分组取自该用户拥有的 `/api/token/` 令牌记录，倍率取自相同用户授权下的 `/api/pricing`。分组倍率只是分组计费系数，不包含模型价格等因素，**不会自动修改本地账号倍率或成本倍率**。动态 `auto`、跨组重试、多个路由分组或无法读取的分组倍率会显示无固定倍率；仍可显示有效的钱包余额。

## 部署、权限与保护

- 默认不配置 New API 授权。配置接口仅限管理员，账号列表不返回系统访问令牌或密文。令牌请求体遵循现有审计脱敏规则。
- 需要固定的 `totp.encryption_key`（环境变量 `TOTP_ENCRYPTION_KEY`），使用现有 SecretEncryptor 加密。自动生成的临时加密密钥不能用于保存授权。备份时必须保留这个固定密钥，否则加密数据不能解密。
- 迁移 `265_new_api_site_authorizations.sql` 增加授权表与账号绑定表，不迁移或删除既有业务数据。数据库备份应包含这两张表。
- 上游必须兼容 New API 用户资料、站点状态、令牌列表接口；读取分组倍率还需要 pricing 接口。受限或自定义部署可能无法完成部分查询。
- 请求沿用账号自身代理、TLS 与 URL 安全策略，禁止自动重定向，并限制超时、分页与响应大小。账号凭据或共享授权更新后，过期探测不能写回旧结果。
- 回退二进制不会撤销数据库迁移。旧程序可忽略新增表；恢复到迁移前数据状态需要恢复对应数据库备份。更换固定加密密钥应另行安排密文重加密。

## 接口与验证

管理员接口位于 `/api/v1/admin/accounts/:id/upstream-billing-probe/config`：GET 获取无密钥的配置与同站点账号，POST `/preview` 验证，PUT 原子保存，DELETE 解除当前账号绑定。

请求包含 `user_id`、可选 `access_token`、`account_ids`，以及歧义时的 `token_selections`（账号 ID 到上游令牌 ID 的映射）。账号、站点或共享授权在验证期间改变时，需要重新验证。

自动化测试覆盖钱包与 Key 额度隔离、用户归属、分页、脱敏冲突、共享授权隔离与原子写入；真实站点仍需使用管理员提供的用户管理授权验证其接口兼容性。
