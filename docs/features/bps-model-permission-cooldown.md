# BPS 模型权限冷却

BPS HTTP 403 的 `basispoints_model_access_changed` 或 `model_not_allowed` 会让当前账号的实际映射模型冷却 30 分钟。指向同一上游模型的别名共用冷却，其他 BPS 模型继续可选；原生 Codex 路径不读取该冷却。

普通 403、401 和 429 保持各自处理规则；该次失败不新增重放，已输出后的工具修复请求若收到模型权限拒绝也记录冷却。模型权限错误不会触发 BPS 整体关闭/移组。观察性质量检测不写入冷却。

状态仅在当前进程内保存，最多 4096 个账号/模型条目，到期回收；达到上限时淘汰最早到期项。重启清空冷却，不修改数据库、凭据、账号状态或计费设置。两条调度路径及粘性账号重检均应用此限制。多实例之间不共享该状态。

设计参考 Sub4API v1.1.5 `ca30f2141bc9ced4cbcfa2ef336f795a94c133e2` 的 `bpsHTTPError`；本 fork 使用 BPS 专属状态，避免其共享 `SetModelRateLimit` 写入影响同账号的原生 Codex 模型。采用独立实现，无整分支移植。

离线回归覆盖两种错误码、HTTP/stream 入口、模型映射别名、过期/容量限制、两种调度模式及原生请求隔离。未发送真实请求或部署。
