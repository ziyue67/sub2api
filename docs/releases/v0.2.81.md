## v2.8.15 / v2.8.16 增量（本次新增）

- **BPS 代理质量调度**：节点按完成率与连通质量排序，轮换代理健康状态与订阅亲和解耦，不健康代理自动故障转移并保留失败诊断
- **BPS 并发会话固定出口**：BPS 并发会话可固定到托管 Mihomo 出口节点，手动 BPS 账号测试带会话身份（见 [BPS Mihomo 会话](../bps-mihomo-sessions.md)）
- **图片中转限额可配置**：图片中转的并发与容量限额改由「系统设置」配置并联动校验（见 [BPS 图片中转限额](../bps-image-relay-limits.md)）
- **Excel / BPS 每请求图片配置**：按请求维度配置 Excel BPS 图片（含 `max_images`）并与协议校验联动（#107）
- **Excel / BPS 401 认证策略**：401 响应统一走认证策略处理，避免被当作普通上游错误透传（#110）
- **BPS 403 自动分组动作**：命中 403 时按分组自动执行预设动作（#105）
- **BPS 原生图片附件与协议补全**：opt-in 的 multipart 附件上传与 `openai_file_id` 回传，`exec_command` 原始文本传输、冗余元数据与历史回放校验（#99 / #100 / #106）
- **BPS 压缩阈值提升**：默认压缩阈值由 780k 提升至 920k
- **BPS 传输纠错**：工具下发前纠正封装错误，传输纠正过程中保留原始载荷，对齐工具历史回放与图片参数校验
- **BPS 限流与重放隔离**：限流状态按账号隔离、有界重放状态按窗口过期，匿名请求与损坏流单独隔离
- **Codex 收割稳定性**：780 路由在校验后跨铸造重试保留（含缓存与错误分类）
- **Pelican 预览修正**：缩略图与全尺寸作品预览适配（#104）
- **Grok 媒体回退**：内置媒体回退改用媒体资格判定
- **OpenAI 兼容修复**：首个上游请求前剥离 reasoning status
- **文档**：新增[新人入门：使用 Sub2API 接入 Codex](../新人入门-使用Sub2API.md)（含 4 张操作截图）、[BPS 图片中转限额](../bps-image-relay-limits.md)、[BPS Mihomo 会话](../bps-mihomo-sessions.md)

## 移植的主要功能

- **管理员请求采集**：按用户 / 上游账户 / 入口分组创建 1–1440 分钟的采集任务，对照请求、响应、工具调用与流式事件；默认关闭，仅保留确认出错的请求或 WebSocket 轮次，正常请求结束即排队清理临时正文
- **Excel / BPS 协议**：单工具调用参数解析、批量设置协议开关与模型范围、缓存创建 token 转普通输入、图片中转入驻控制，以及用量明细中的推理等级映射
- **凭证守护**：令牌巡检、自动重登与错误态自愈（默认关闭）
- **账号质量运维**：检测规则、判定与告警、批量设置 Excel / BPS 选项
- **Codex 并行收割与 780 原生铸造**、**Codex 门票（x-codex-turn-state）打票与注入**
- **Mihomo 托管 / 国家过滤 / 动态代理区域**：含 Codex 门票出口池与本地内核迁移脚本
- **BPS 代理运行时**：节点按完成率与连通质量排序、BPS 并发会话固定托管出口、不健康代理故障转移与失败诊断保留（[文档](../bps-mihomo-sessions.md)）
- **Pelican 定时演练与展示页**
- **请求时延明细**：新增请求耗时与 TPS 统计口径
- **分组维度扩容**：上游分组倍率、分组允许模型、用户分组拒绝模型、仅流式分组
- **Copilot SDK 接入教程**与 **Cyber 会话屏蔽**能力
- **字节点（BPS）自定义传输层**与相关回归测试

  `curl -sSL https://raw.githubusercontent.com/ziyue67/sub2api/v0.2.81/deploy/install.sh | sudo bash -s -- upgrade`。
- **回滚方式（二进制）**：`install.sh rollback <version>`，或直接下载目标版本归档替换 `/opt/sub2api/sub2api` 后 `systemctl restart sub2api`。
