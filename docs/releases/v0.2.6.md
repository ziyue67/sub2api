> [!IMPORTANT]
> 本版本为 **0.2.6 测试版**：基于 v0.2.7 正式版合并之后构建，额外包含 0.2.6 测试功能（Codex 292 打票）。
> `latest` 与正式版仍指向 **0.2.7**，本版本只提供 `0.2.6` 与 `0.2.6-amd64` 标签。

## 新增功能（测试）

- **Codex 292 门票（x-codex-turn-state）打票与注入**：通过独立的 HTTP(S)/SOCKS 代理后台打票，捕获 292 长度门票，默认缓存 1 小时（`ttl_seconds: 3600`，提前 600 秒刷新），再在住宅 IP 业务请求中覆盖该头
- **门票生命周期加固**：门票写入与调度、账号编辑路径解耦；账号级 `codex_turn_ticket:` 状态持久化
- **后台开关**：系统设置 → 网关 → Codex 设置 → 「292 打票」，可覆盖配置文件 `enabled`，保存后无需重启；账号列表/编辑页展示门票状态（剩余时间 / 未打到 292 已暂停）
- **缺票拦截（fail_closed）**：未打到有效门票的模型暂停调度，避免裸打业务请求
- **配置项**：`gateway.openai_codex_ticket.*`（target_length 292 / ttl 3600 / harvest_proxy_url / 探测间隔 6s / 超时 25s / models: gpt-6-astra、gpt-5.6-sol）
- **环境变量**：`GATEWAY_OPENAI_CODEX_TICKET_ENABLED`、`GATEWAY_OPENAI_CODEX_TICKET_HARVEST_PROXY_URL`
