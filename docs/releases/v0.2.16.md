## 上游增量（v0.2.16）

### Gemini 显式缓存（本次最大特性）

- **支持显式上下文缓存**：覆盖 AI Studio、Vertex 与自建网关上游（`cachedContents`）
- 缓存存储价内置官方价，并按 Pro / Flash 系列兜底；3.6 Flash 兜底价改为官方优惠价
- 缓存修改串行化、失败回滚；确定金额费用按 Key / 订阅预留
- 缓存错误透传收窄到上游网关账号，延长沿用创建时的计费口径
- 恢复流程区分「账号已删除」与「暂不支持缓存」；上游必已过期后作废意图
- 引用缓存不存在的 403 不再停用账号并换号

### Gemini / Vertex 账号能力

- **Vertex 账号支持 API Key 认证**；Vertex 服务账号支持同步上游模型列表
- 适配 AI Studio `AQ.` 格式 Key
- 模型列表与模型详情接口支持 Agent Platform (Vertex) 账号
- 第三方上游 API Key 与 Vertex 不再套用 AI Studio 等级和模拟配额
- 界面显示名统一为 **Agent Platform (Vertex)**

### 网关与计费

- **接入 Claude Haiku 5.5**，并接入 Responses 桥接（含采样边界与默认模型配置修正）
- Responses 到 chat 的兜底保留 Responses 语义；结构化输入回退增加不安全重试护栏
- Antigravity 图片模型限流隔离
- 账号计数、Bedrock 与重试耗尽入口把上游模型交给错误处理
- 显式模型级 401 规则在网关故障转移入口生效
- 识别国际版 coding 端点（配额）
- Ops：Gemini 原生路由的网关本地错误按错误类型归类

### 其他

- **分组名称与描述支持多语言**（广场 `Vary` 保留 Origin，译文语言代码统一大小写）
- 账号同步上游模型失败时显示后端返回的错误原因
- 依赖安全更新：SheetJS、Vue 与 source-map 补丁
- 前端：模型白名单回归用例纳入 CI

## Fork 侧保留与合并处理

本次合并共 **24 个冲突文件**，全部按「保留 Fork 行为 + 采纳上游新增」处理：

- **ent 生成代码**：`ent/migrate/schema.go`、`ent/runtime/runtime.go` 由 `go generate ./ent`
  按合并后的 schema 重新生成（`groups.i18n` 字段加入后列索引整体位移，手改极易静默错位）。
  生成结果与生成器幂等，未引入仓库既有形态之外的新文件。
- **`wire_gen.go`**：`provideCleanup` 实参按函数形参顺序取两侧并集（57 个实参），
  补入上游新增的 `geminiCachedContentService`。
- **`gateway_usage_billing.go`**：采纳上游的 `recordUsageMultipliers` / `recordUsageBillingModel`
  辅助函数，并把 Fork 的账号级分组倍率（`account.UserGroupRateMultiplier()`）、
  宿主工具基准倍率 `baseMultiplier` 与 `withModelBillingConfig` 策略快照恢复进去。
- **`gemini_messages_compat_service.go`**：Fork 的 `SelectAccountForAIStudioEndpoints` /
  `ForwardAIStudioGET` 已被上游的 `SelectAccountForModelsEndpoints` / `ForwardListModels`
  取代，删除重复实现；并把 Fork 的 `projectGeminiLaneSelection`（代理车道投影）接到上游选号函数上，
  车道语义不丢。`gemini_v1beta_handler.go` 保留 Fork 的 API Key 并发槽保护。
- **`openai_account_runtime_block_fastpath.go`**：保留 Fork 直调策略主体的写法（调用方已重置
  401 连击），同时采纳上游的临时不可调度作用范围（scope）判定。
- **`openai_gateway_responses_chat_fallback.go`**：保留 Fork 的 DeepSeek 原生 compaction
  改写分支，`startTime` 跟随上游改为形参传入。
- **`scheduler_cache.go`**：候选投影键取并集（Fork 的 `model_mapping_mode` + 上游 Gemini 显式缓存键）。
- **`available_channel_handler.go`**：`userAvailableGroup` 采纳上游的 `i18n` 字段，
  `toUserAvailableGroup` 同步带上，保证分组文案本地化不丢。
- **`model_plaza_handler.go`**：上游的语言本地化包装与 Fork 的用户禁用模型过滤合并为
  `toLocalizedModelPlazaGroups(..., deniedModels)`。
- **`usage_handler.go`**：观察者分支保留 Fork 的管理端 DTO，并补上 `Localized`（新增
  `AdminUsageLog.Localized`），满足「用户侧分组 DTO 必须本地化」的上游守卫测试。
- 其余（`admin_group.go`、`dto/types.go`、`dto/mappers.go`、`account_test_service.go`、
  `repository/wire.go`、前端 i18n 与各 spec）均为并集。
