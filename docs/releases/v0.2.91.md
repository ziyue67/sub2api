## 升级说明

- **升级方式**：管理后台左上角「检查更新」可一键升级；也可在服务器执行
  `curl -sSL https://raw.githubusercontent.com/ziyue67/sub2api/v0.2.91/deploy/install.sh | sudo bash -s -- upgrade`。
- **回滚方式**：`install.sh rollback <version>`。
- 也可以使用 Docker 镜像部署：`docker pull ghcr.io/ziyue67/sub2api:0.2.91`，具体见 [部署文档](../../deploy/README.md)。
- **镜像只提供 `linux/amd64` 单架构**（不产出 arm64；`install.sh` 在 arm64 上会明确报错），标签为 `0.2.91` / `0.2.91-amd64` / `latest`（同一镜像）。
- **二进制归档停发（2026-09-27 起）**：Release 不再附带 `sub2api_*.tar.gz` / `*.zip` 与 `checksums.txt`，统一以 Docker 镜像交付。
- **数据库迁移**：本次新增 `253_pelican_group_tests.sql`，启动时自动执行；上一次追平（`v2.8.19` / `v2.8.20`）无新增迁移。升级前请备份数据库。
- 请求采集与凭证守护默认关闭，需在「系统设置 > 功能开关」中显式启用。
- 安装脚本与在线更新服务的默认仓库为 `ziyue67/sub2api`（`backend/internal/service/update_service.go`、`deploy/install.sh`）。
