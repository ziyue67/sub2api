> AI API Gateway Platform - 将 AI 订阅配额分发和管理

补齐 0.2.1 → 0.2.2 的累计变更：网关各入口强制校验分组模型白名单，Simple 模式支持基础账号分组，并集中修复 Codex / Claude / OpenAI 适配与计费口径问题。

> 说明：上游 `Wei-Shaw/sub2api` 未单独发布 `v0.2.2` 的 Release，本说明依据 `v0.2.1...v0.2.2`（57 个提交）整理。

## 新增功能

- 分组模型白名单：网关各端点统一强制校验分组的 `model_allowlist`（含数据库迁移与前端配置界面）
- Simple 模式支持基础账号分组，并配套分组能力白名单与分组删除守卫
- OpenAI 标准模型发现复用已绑定（pinned）账号，减少无效探测
- 账号新增「按月 / 按年」到期时间预设
- 管理端订阅列表关联展示用户用量
- 分组的推理强度映射支持「拒绝转发」策略

## 优化改进

- 模型广场定价列宽自适应，可容纳缓存价格；仅按倍率定价的区间价格单独展示
- i18n 缺失语言键直接让构建失败，避免出现残缺界面
- 渠道监控 Gemini 探测显式携带用户角色
- Antigravity 默认 User-Agent 版本刷新
- Grok 跨客户端映射默认值说明文案修正

## Bug 修复

- 修复 Claude Code 版本伪装未真正生效、Fable 5.1 请求仍被上游 400 拒绝的问题；指纹自愈路径同样执行 `claude-cli` 版本下限
- 修复 Codex / Astra 相关问题：GPT-6 Astra 指令选择错误、Astra Ultra workflow 元数据丢失、Astra 输入模态过期、Astra 推理模式在 OAuth 下未保留、`allowed_tools` 选择约束未保留
- 修复 OpenAI 混合账号目录丢失默认模型、命名 standalone Responses 输入被丢弃、流式失败缺少上游诊断信息、passthrough turn 槽位未回收、HTTP bridge 连接状态未隔离
- 修复模型未找到时网关未按预期故障转移
- 修复计费口径：DeepSeek 高峰账号成本少计、`glm-5.3` / `glm-5.3-flash` 兜底价被 `glm-5` 子串匹配抢占、Gemini 3.7 / 3.8 Flash thinking 档位价格、Grok 未决账号被误判为不可计费、Fable credits 错误未按模型收敛
- 修复备份 `pg_dump` / `psql` 未与迁移 `advisory lock` 串行化
- 修复支付履约与兑换限额未隔离，兑换失败窗口改为固定 10 分钟
- 修复 Anthropic Messages 兼容层丢弃 done 事件中的参数
- 前端修复：Turnstile 加载占位、Codex manifest 编辑状态保留、onboarding 按钮阴影、Codex manifest 编辑后未即时生效、使用记录筛选未加载全部 API Key
