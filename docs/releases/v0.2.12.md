## 升级说明

- **升级方式**：管理后台左上角「检查更新」可一键升级；也可在服务器执行
  `curl -sSL https://raw.githubusercontent.com/ziyue67/sub2api/v0.2.12/deploy/install.sh | sudo bash -s -- upgrade`。
- **回滚方式**：`install.sh rollback <version>`。
- 也可以使用 Docker 镜像部署：`docker pull ghcr.io/ziyue67/sub2api:0.2.12`，具体见 [部署文档](../../deploy/README.md)。
- **镜像只提供 `linux/amd64` 单架构**（不产出 arm64；`install.sh` 在 arm64 上会明确报错），标签为 `0.2.12` / `0.2.12-amd64` / `latest`（同一镜像）。
- **Release 零附件**：不附带 `sub2api_*.tar.gz` / `*.zip` / `checksums.txt`，统一以 Docker 镜像交付。
- **数据库迁移**：新增 `241_add_typesafe_platform.sql`（`accounts.platform` 约束加入 `typesafe`）与
  `241_add_payment_order_bonus_amount.sql`（`payment_orders.bonus_amount`），启动时自动执行。升级前请备份数据库。
- **重置密码链接失效提醒**：重置 token 改为哈希存储，升级前已发出但尚未使用的链接将失效，用户需重新申请。
- 请求采集与凭证守护默认关闭，需在「系统设置 > 功能开关」中显式启用。
- 安装脚本与在线更新服务的默认仓库为 `ziyue67/sub2api`（`backend/internal/service/update_service.go`、`deploy/install.sh`）。
