## 升级说明

- **升级方式**：管理后台左上角「检查更新」可一键升级；也可在服务器执行
  `curl -sSL https://raw.githubusercontent.com/ziyue67/sub2api/v0.2.13/deploy/install.sh | sudo bash -s -- upgrade`。
- **回滚方式**：`install.sh rollback <version>`。
- 也可以使用 Docker 镜像部署：`docker pull ghcr.io/ziyue67/sub2api:0.2.13`，具体见 [部署文档](../../deploy/README.md)。
- **镜像只提供 `linux/amd64` 单架构**，标签为 `0.2.13` / `0.2.13-amd64` / `latest`（同一镜像）。
- **Release 零附件**：不附带 `sub2api_*.tar.gz` / `*.zip` / `checksums.txt`；重登运行包仅在手动勾选 `publish_reauth_runtime` 时上传。
- **数据库迁移**：新增 `237_add_api_key_concurrency_limit.sql`（`api_keys.concurrency_limit bigint not null default 0`，含非负约束），启动时自动执行。
- **Prism 桥接为可选部署**：`prism-adapter/` 需自行部署（README + systemd 单元），未部署时不启用该路由。
- 请求采集与凭证守护默认关闭，需在「系统设置 > 功能开关」中显式启用。
- 安装脚本与在线更新服务的默认仓库为 `ziyue67/sub2api`（`backend/internal/service/update_service.go`、`deploy/install.sh`）。
