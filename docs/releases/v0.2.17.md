## 上游增量（v0.2.17）

### Antigravity / Gemini

- **支持 Gemini 4 Argon**（含 `low`/`medium`/`high` 档位）与准确的上游模型目录；补齐 Argon 计费
- 保留 `tool_result` 图片、原生 Gemini `functionCall` 与 `thoughtSignature`，以及 composite `/v1beta` 路由
- 保留旧默认透传，Claude 5.5 tier ID 按基础价计费
- Gemini 兼容入口转发思考档位并流式返回思考摘要
- Vertex 共享容量不足的 429 不再冷却账号，改为同号退避重试；服务账号已不存在时账号置为 error 并换号
- 每个上游错误响应只检查一次错误策略

### 网关与协议

- **拒绝含 OpenAI 网关 OAuth 的 composite 歧义路由**，防止凭据误入 Anthropic 管线
- 网关照 Anthropic 协议的 base URL 生效
- Responses 对象一律带 `created_at`（修复 grok-build 反序列化失败）
- 结构化输入最小输出 token 下限可配置（`gateway.min_output_tokens`，最小 16，默认 128）
- 智谱 GLM Coding Plan 5h / weekly 用量窗口修正
- 模型退役判定改在公开别名投影**之后**评估；GPT-5.5 在 ChatGPT 上游按退役处理

### OpenAI / Codex

- `/v1/messages` 对 OpenAI API Key 账号模拟 `web_search`；OAuth 账号排除该模拟
- Codex 导入按 workspace 隔离

### 支付

- EasyPay：下单查询与到账前确认通知修复
- 支付宝：退款状态查询、不支持订单类型的关闭、待处理退款原子收尾、退款查询错误按待处理处理
- Stripe：client secret 从本地订单快照读取
- 订单类型校验，待处理期间保留退款扣减

### 前端

- 恢复内联账号筛选（revert `#7853`）
