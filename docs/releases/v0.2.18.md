## 上游增量（v0.2.18）

### 账号与调度

- **Vertex 账号支持配额上限**，与 API Key / 服务账号配额口径统一
- 账号配额累加按已设置的周期维度选择语句（日/周/月维度不再写多份）
- **调度快照解码结果常驻进程内存**：只有在 ready、active 版本、全局修订号与平台修订号都与 Redis
  一致且未超最长复用时长时才复用；`last_used` 每次仍从 Redis 读取
- 解码结果靠 `EXISTS` 校验元数据未删除，删除/撤销会使温缓存立即失效
- 单 antigravity 账号的分组判定改为按需求值
- 模型映射签名改为与遍历顺序无关、零分配
- 模型限流快照写入改为写时复制，避免候选对象被跨 bucket 污染
- 账号列表的平台与状态筛选可持久化

### 网关与协议

- **Anthropic 账号 chat/responses 兼容流式：客户端断开后读完上游再计费**（不再漏计）
- 兼容流上游未正常结束时按错误收尾，并与原生 SSE 收尾对齐
- Codex overload：合并身份判定与空流安全重试修复，排队事件与 metadata 事件之后仍保留重试
- 工具参数常量与注解归一化
- Cloudflare 1010 拦截不再惩罚账号（按边缘拦截处理）

### Gemini / 生图

- **分组「允许当前分组生图」开关对 Gemini 系入口生效**（含迁移 246）
- Gemini prompt 被拦截、只报缓存命中时 `input_tokens` 不再为负
- Gemini 流式中途客户端断开时按已收集用量计费
- DeepSeek 图片输入避免重复载荷（按账号凭据选定单一 URL 字段）
- 异步生图转存的图片下载与同步回填策略对齐

### 计费

- Grok 4.7 Fast 按官方 Fast 价卡计费

### 构建与安全

- Docker 构建镜像对齐 Go **1.27.3**，CI 版本校验同步
- `dompurify` 升级至 **3.4.17**，修复 GHSA-cg2g-xh64-v4q7（critical）与 GHSA-mrv2-3pqr-j5jr（high）
