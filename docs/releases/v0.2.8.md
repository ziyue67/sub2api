## 上游同步（v0.2.7 → v0.2.8）

合并上游 237 个提交 / 473 个文件，手动解决 36 个文件的冲突。

### 来自上游的新功能

- **OpenCode Go 官方用量窗口**：可主动查询周 / 月用量，`7d` / `1m` 徽章展示，同 Key 组共享、活动防抖、超窗强刷；支持挂载到 openai / anthropic / kimi / zhipu / deepseek / minimax 平台账号，并新增 `/zen/go` 基址变体
- **新模型支持**：GPT-6 Sol / Luna、Claude Opus 5.5、Grok 4.7
- **Claude Code 客户端版本号自动同步**：新增设置项 `claude_code_client_version` / `claude_code_client_version_synced` / `claude_code_version_auto_sync_enabled`
- **可配置 reasoning effort 计费倍率**（新增迁移 239）
- **Codex credits 展示与 referral 邀请管理**
- **备份月度归档 + 独立保留策略**（S3 secret 继承时保持加密）
- **可配置滚动日志保留**
- **Affiliate 线下提现登记**（按 Idempotency-Key 幂等，新增迁移 240）
- **simple mode**：可选强制 API-key 消费窗口；启动时默认分组创建可选
- **content-audit 独立 TypeSafe 引擎配置**（新增迁移 238b）
- **插件 HostService 账号目录返回结构化只读元数据**

### 来自上游的重要修复

- **OpenAI**：流式改为以终止事件收尾（不再等待上游 EOF）、恢复 HTTP/2 保活容错期限、Codex turn metadata 保留非 ASCII、Responses item id 清洗与流式错误一次性输出
- **Gemini / Vertex**：429 冷却到 PST 午夜并遵守 RetryInfo、传输层错误转为 failover、Antigravity 裸模型名解析到思考变体并改写身份避免 429
- **工具 Schema**：清洗非法的 `null required`，修复上游返回 400
- **代理**：过期边界判定、回退恢复探测、跳过不活跃的 fallback 目标
- **调度**：非高级调度按 `previous_response` 路由到持有响应的账号、调度倍率补充账号倍率回退
- **前端**：20+ 处竞态 / 陈旧请求修复（IME 输入、日期选择器、dialog 滚动锁、TOTP 计时等）

## Fork 自有功能（完整保留）

- **Codex 292 门票（x-codex-turn-state）打票与注入**：独立代理后台打票、住宅 IP 请求覆盖该头，含后台开关、门票状态展示与缺票拦截
