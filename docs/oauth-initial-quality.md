# OAuth 首次质量规则

在「自动配置 → OAuth 账户首次配置 → 首次加入质量运维」选择已有质量规则并保存。选择列表显示来源账号、规则编号、模型和处置方式；已保存的副本展示模型、计划和启停状态。

- 首次配置启用后，仅为所选平台的新 OAuth 账号复制规则，包含普通创建和 CRS 新账号导入。观察者导入不继承管理员的全局首次配置。
- 复制检测模型、题目、判题器、计划、处置方式、恢复选项、历史保留数和启停状态。原规则已暂停时，新规则也暂停。
- 保存的是独立快照。以后修改或删除来源规则不会改变副本；需要更新时重新选择规则并保存。新账号生成的规则可在质量运维中单独调整。
- 选择「不自动加入质量运维」停止后续自动创建；不删除已有账号的规则。切换 OAuth 平台会清空质量规则选择，OpenAI 状态探针不用于其他平台。
- 账号和质量规则在同一数据库事务中创建，规则写入失败时账号也不落库。已有账号更新、重新授权不创建规则。

配置以 `quality_rule` 保存在现有自动配置 setting 中，不增加数据库迁移。旧配置缺失该字段时保持原行为。新账号仍可能匹配质量运维中的分组规则，现有同类规则去重逻辑继续适用。
